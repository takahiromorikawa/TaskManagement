# 機能要件：TaskManagement

## 機能一覧（MVP）

| 機能 | 内容 |
|---|---|
| カード作成 | タイトル・優先度（高／中／低）・期限（任意）を入力してカードを新規作成する |
| カード一覧取得 | 登録されている全カードを取得する |
| カード詳細取得 | IDを指定して1件のカードを取得する |
| カードの編集 | タイトル・優先度・期限を変更する（ステータスは変更しない） |
| カードのステータス変更 | カードをドラッグ&ドロップし、「未着手／進行中／完了」の間を自由に移動する（前後の方向を問わない） |
| カードの並び替え | 「追加順／期限順／優先度順」でカード一覧の表示順を切り替える |
| カード削除 | カードを削除する |

以下は今回のスコープ外（将来的な拡張候補）とする。

- ログイン・ユーザー管理機能
- 複数ボード機能
- 担当者などの付加情報（優先度・期限は今回のスコープに含む）
- タッチ操作でのドラッグ&ドロップ（マウス操作前提のHTML5 Drag and Drop APIを使用するため、タッチ操作での動作は保証しない）

## ユースケース・操作フロー

### UC1: カードを新規作成する

- アクター: 利用者（自分）
- 事前条件: カンバンボード画面（S1）を開いている
- 基本フロー:
  1. 「+ 新規作成」ボタンをクリックし、S2を開く
  2. タイトルを入力し、優先度（高／中／低、デフォルト「中」）を選択する
  3. 期限を入力する（任意。未入力可）
  4. 「作成」ボタンを押すと `POST /cards` が呼ばれ、カードが作成される
  5. S1の「未着手」列に新しいカードが表示される
- 代替フロー:
  - タイトルが未入力の場合、送信せずエラーメッセージを表示する

### UC2: カード一覧を確認する

- 事前条件: なし
- 基本フロー:
  1. カンバンボード画面（S1）を開く
  2. `GET /cards` が呼ばれ、全カードを取得する
  3. 取得したカードをステータスごとに3列へ振り分けて表示する
  4. 選択中の並び替え条件（追加順／期限順／優先度順）に従って、各列内のカードを並べる

### UC3: カードのステータスを変更する

- 事前条件: 移動対象のカードが存在する
- 基本フロー:
  1. 対象カードをドラッグし、移動先の列（未着手／進行中／完了）の空いている領域にドロップする
  2. `PUT /cards/{id}/status` が呼ばれ、ドロップ先のステータスに更新される（列内では末尾に追加される）
  3. カードが該当する列へ移動する
- 補足:
  - 前の列に戻す操作（例：完了→進行中）も同じ操作で行える
  - 別の列の特定のカードの上にドロップした場合は、ステータス変更と同時にそのカードの直前/直後（UC5参照）に挿入される
  - 同じ列内の別カードの上にドロップした場合はステータスを変更せず、UC5（並び替え）のみを行う

### UC4: カードを削除する

- 事前条件: 削除対象のカードが存在する
- 基本フロー:
  1. 対象カードの「削除」ボタンをクリックし、S3（削除確認ダイアログ）を開く
  2. 「削除」を押すと `DELETE /cards/{id}` が呼ばれる
  3. カードが一覧から消える
- 代替フロー:
  - 「キャンセル」を押した場合、削除せずダイアログを閉じる

### UC5: カードを並び替える

- 事前条件: 並び替え対象の列にカードが2件以上存在する
- 基本フロー（並び替え条件を切り替える場合）:
  1. 画面上部の並び替えセレクトで「期限順」または「優先度順」を選択する
  2. 全列のカードが、選択した条件（期限の早い順／優先度の高い順）で並び直される
- 基本フロー（手動で並び替える場合）:
  1. 並び替え条件が「追加順」の状態で、カードを同じ列内、または別の列内の別カードの上にドラッグ&ドロップする
  2. ドロップ先カードの上半分にドロップすると直前に、下半分にドロップすると直後に挿入され、`PUT /cards/reorder` が呼ばれて並び順がサーバーに保存される
  3. 別の列のカードにドロップした場合は、挿入と同時にUC3のステータス変更も行われる
- 補足:
  - 手動並び替えを行うと、並び替え条件は自動的に「追加順」に切り替わる
  - 手動で並び替えた順序はサーバーに保存されるため、画面を開き直しても維持される

### UC6: カードを編集する

- 事前条件: 編集対象のカードが存在する
- 基本フロー:
  1. 対象カードをクリックし、S4（カード編集フォーム）を開く
  2. タイトル・優先度・期限を変更する
  3. 「保存」ボタンを押すと `PUT /cards/{id}` が呼ばれ、カードが更新される
  4. ポップアップが閉じ、変更後の内容がカードに反映される
- 補足:
  - ステータスはこの操作では変更しない（ステータス変更はUC3のドラッグ&ドロップのみで行う）
- 代替フロー:
  - タイトルが未入力の場合、送信せずエラーメッセージを表示する

### 全体の操作フロー（概略）

```
カンバンボード表示（UC2）
   │
   ├─ [+ 新規作成] → 新規作成フォーム（UC1） → 未着手列に追加
   │
   ├─ カードをドラッグして列の空き領域へドロップ → ステータス変更（UC3） → 該当の列の末尾へ移動
   │
   ├─ カードを別カードの上（同じ列／別の列）へドロップ / 並び替えセレクトを変更 → 並び替え（UC5、別の列の場合はUC3も同時に実行）
   │
   ├─ カードをクリック → カード編集フォーム（S4／UC6） → タイトル・優先度・期限を更新
   │
   └─ カード「削除」 → 削除確認（UC4） → 一覧から削除
```

各ユースケースの画面上の操作対象は[画面仕様](screens.md)、バックエンドとのやり取りは[API仕様](api.md)のシーケンス図を参照。
