# 開発サーバー起動（ポート競合を必ず解消する）

TaskManagementプロジェクトの開発サーバーを起動する際は、必ずこの手順に従う。
別ポートへの変更や、Viteが自動提案する代替ポート（5174など）をそのまま受け入れることは禁止。必ずデフォルトポートで起動し直す。

## デフォルトポート

- バックエンド（Spring Boot）: `8080`
- フロントエンド（Vite）: `5173`

## 手順

### 1. ポート競合の確認と解消（必須・最優先）

起動対象のポートを、既に別プロセスが使用していないか必ず確認する。

```bash
lsof -ti:8080   # バックエンド用ポートの確認
lsof -ti:5173   # フロントエンド用ポートの確認
```

出力があれば（＝ポート使用中）、そのプロセスを停止してから次に進む。

```bash
lsof -ti:8080 | xargs kill
lsof -ti:5173 | xargs kill
```

停止後、プロセスが完全に終了しているか（`lsof -ti:<port>`が空になるか）を確認してから起動処理に進む。

### 2. バックエンドを起動する場合

PostgreSQLが起動していなければ先に起動する。

```bash
docker compose up -d
./gradlew bootRun
```

### 3. フロントエンドを起動する場合

```bash
cd frontend
npm run dev
```
